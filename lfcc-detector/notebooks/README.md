# Notebooks (Optional)

Jupyter notebooks for exploratory analysis, visualization, and debugging.

## Suggested Notebooks

- `01_data_exploration.ipynb`: Visualize audio, check label balance, duration distribution
- `02_feature_visualization.ipynb`: Plot LFCC features, compare bonafide vs spoof
- `03_model_debugging.ipynb`: Debug training issues, visualize embeddings
- `04_error_analysis.ipynb`: Analyze misclassified samples

## Setup

```bash
pip install jupyter
jupyter notebook
```

These are gitignored by default (see `.ipynb_checkpoints` in root `.gitignore`).
