Backend :
cd realtime-backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Decision expert = mc_v3 (multi-corpus V3 LFCC-LCNN, measured unseen-generator
# generalization) paired with its matched calibrator; all experts' raw scores still reported.
EXPERTS=wavlm,lfcc,hindi,mc_v3 SINGLE_EXPERT=mc_v3 CALIBRATOR_PATH=artifacts/calibrator_mc_v3_combined.json DEVICE=cuda python server.py

Frontend :
cd voice-integrity-frontend
npm install
npm run dev

Backend : http://localhost:8000
Frontend : http://localhost:5173

These commands work for linux and macos.




For windows use the following commands (in PowerShell):

Backend :
cd realtime-backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
# Decision expert = mc_v3 (multi-corpus V3, measured generalization) + its matched calibrator.
$env:EXPERTS="wavlm,lfcc,hindi,mc_v3"; $env:SINGLE_EXPERT="mc_v3"; $env:CALIBRATOR_PATH="artifacts/calibrator_mc_v3_combined.json"; $env:DEVICE="cuda"; python server.py

Frontend :
cd voice-integrity-frontend
npm install
npm run dev

Backend : http://localhost:8000
Frontend : http://localhost:5173
