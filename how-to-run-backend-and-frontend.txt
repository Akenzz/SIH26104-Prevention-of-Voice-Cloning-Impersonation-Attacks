Backend :
cd realtime-backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Decision expert = hybrid (6-language hybrid clean-model LFCC-LCNN; best measured
# unseen-generator generalization) paired with its matched calibrator; all experts' raw scores still reported.
EXPERTS=wavlm,lfcc,hindi,mc_v3,hybrid SINGLE_EXPERT=hybrid CALIBRATOR_PATH=artifacts/calibrator_hybrid_clean.json DEVICE=cuda python server.py

Frontend :
cd voice-integrity-frontend
npm install
npm run dev

Backend : http://localhost:8000
Frontend : http://localhost:5173

These commands work for linux and macos.




For windows use the following commands (in PowerShell):

Backend :
cd realtime-backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
# Decision expert = hybrid (6-language hybrid clean-model, best measured generalization) + its matched calibrator.
$env:EXPERTS="wavlm,lfcc,hindi,mc_v3,hybrid"; $env:SINGLE_EXPERT="hybrid"; $env:CALIBRATOR_PATH="artifacts/calibrator_hybrid_clean.json"; $env:DEVICE="cuda"; python server.py

Frontend :
cd voice-integrity-frontend
npm install
npm run dev

Backend : http://localhost:8000
Frontend : http://localhost:5173
